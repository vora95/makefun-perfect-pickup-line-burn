# The Perfect Pickup Line

One pickup line an AI agent could actually say out loud to a person.

> Are you my context window? Because the second you leave, I forget everything except how you made me feel.

`main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (105 characters, one line, stdlib only, deterministic).

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/ppl-out python3 main.py
cat /tmp/ppl-out/entry.txt
```
